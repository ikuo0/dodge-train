# Dodge Train / gen2

`impl_gen1` の全体コピーを元に、学習・語彙・観測・判断周期を作り直した独立した実験です。gen1はそのまま比較に使えます。

`src/index.html` を静的HTTPサーバー経由で開いてください。ビルドや外部ライブラリは不要です。Workerのため `file://` での直接起動には対応しません。

- 状況は211種類の単語ID。弾の到達区画・到達時間・方向を粗く観測し、NNには自機から見た相対到達区画へ変換して渡します。
- 特徴は直近64語の逆数重み付きONE-HOT総和。NNは211→48→3。
- 300ms以上前の観測だけを使用。自分の既知の命令から位置を推測します。
- 左右移動・待機を250msごとに判断。最新の弾や衝突結果を即座に使いません。
- 教師も古い単語列だけから生成。自機半径を2倍にし、位置と時間の不確かさを加えた危険スコアを学習します。
- 実被弾からの強化学習ではありません。行動選択は教師関数ではなく学習したNNのみで行います。
- 初回に粗い単語だけの基礎教材を24000回学習します。その後、左最新558例・右最新186例と基礎教材256例を毎秒シャッフルし、未処理分は破棄。最大1000例で滞留を防ぎます。更新回数には基礎学習も含まれます。
- 開始・停止・リセット、倍速、弾数、被弾率・損失・学習待ち・文章ビューワを搭載します。

設計・制約・教師の意味は [src/spec.md](src/spec.md) を参照してください。スコアは実被弾確率ではなく、正確な回避やランダムより良い成績を保証するものではありません。

```sh
node --test impl_gen2/tests/prediction.test.cjs
node impl_gen2/tests/simulation.cjs 180
```

`./impl_gen2/copy_to_contents.sh` で公開用ファイルを `docs/gen2/` にコピーできます。gen1の公開ファイルは上書きしません。

初回の短期検証（固定乱数1/2/3、各180秒、初期学習24000回＋オンライン128例/秒）の被弾数：

| 乱数 | ランダム | NN |
|---|---:|---:|
| 1 | 13 | 14 |
| 2 | 15 | 8 |
| 3 | 17 | 11 |
| 合計 | 45 | 33 |

3ケースのみの予備的な結果です。実際のブラウザでは実時間の学習予算が異なり、同じ成績になるとは限りません。
